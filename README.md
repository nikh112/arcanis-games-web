# Arcanis Games 

A reactive, component-driven web portfolio built to showcase live Roblox games.

https://arcanis-games.vercel.app/

* **Component Based:** Modular React architecture utilizing custom `Slideshow`, `GameGallery`, and `ScrollProgress` as well as other components for a scalable codebase.
* **Responsive Layouts:** Styled entirely with Tailwind CSS
* **Optimized Media Handling:** Implements lazy loading for heavy video and image assets
